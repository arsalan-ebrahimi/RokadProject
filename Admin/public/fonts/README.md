# IRANSansX Font Files Directory

برای استفاده از فونت اختصاصی **IRANSansX**، فایل‌های زیر را با فرمت `.woff2` یا `.woff` در همین پوشه (`public/fonts/`) قرار دهید:

### فایل‌های مورد نیاز:
- `IRANSansX-Regular.woff2` (یا `.woff`) - وزن عادی (۴۰۰)
- `IRANSansX-Medium.woff2` (یا `.woff`) - وزن متوسط (۵۰۰)
- `IRANSansX-DemiBold.woff2` (یا `.woff`) - وزن نیمه‌ضخیم (۶۰۰)
- `IRANSansX-Bold.woff2` (یا `.woff`) - وزن ضخیم (۷۰۰)
- `IRANSansX-Black.woff2` (یا `.woff`) - وزن مشکی/سنگین (۹۰۰)
- `IRANSansXFaNum-Regular.woff2` (یا `.woff`) - اعداد فارسی (۴۰۰)
- `IRANSansXFaNum-Bold.woff2` (یا `.woff`) - اعداد فارسی ضخیم (۷۰۰)

> **توجه:** در صورت عدم وجود این فایل‌ها، پروژه به صورت خودکار از فونت آزاد **Vazirmatn** استفاده می‌کند.
